# The World in One Day — 19 November 2026

Entry for the make.fun bounty **"Sum up 19 November's world news in one image"**
(https://make.fun/bounty/news-image-20261119).

`main.py` (Python 3.13, Pillow only) draws a deterministic 1024×1024 front
page summarising Thursday 19 November 2026 — ICJ genocide ruling on Myanmar,
the Trump–Xi–Putin Shenzhen summit, Anthropic's record $81bn IPO, GTA VI
launch day, markets, and eight briefs — and writes it to `/output/entry.png`.

No network access; two runs produce identical bytes. Run locally with:

```
OUTPUT=./entry.png python3 main.py
```
